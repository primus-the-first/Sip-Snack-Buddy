Sip & Snack Buddy 0.5.1: steps that keep counting

- Fixed: steps barely went up. The phone's step counter only counts while an app is listening, and the app only listened for a moment at a time. Now it listens all day.
- A quiet notification shows today's steps while it counts. Turn it off in Settings > Count steps all day (steps then only count while the app is open).
- Counting picks up again by itself after the phone restarts or the app updates.

Tap Update in the app, or install `SipSnack-0.5.1.apk` below. It keeps all logs. Steps taken before this update can't be recovered, so today's count starts from when you install it.
