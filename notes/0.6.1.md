Sip & Snack Buddy 0.6.1: steps no longer carry over past midnight

- Fixed: if the phone didn't record steps across midnight (for example the app was asleep for a long stretch), everything walked since the last look was counted as today, so yesterday's steps showed up on the new day.
- Now each reading uses the time of the latest step. Steps from before midnight stay on yesterday, and a gap that spans midnight is shared by time.
- Today's count may drop once after updating. That's the correction.

Tap Update in the app, or install `SipSnack-0.6.1.apk` below. It keeps all logs.
